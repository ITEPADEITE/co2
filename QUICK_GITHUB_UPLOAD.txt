✅ STATUS: Git repository sudah ready di folder lokal

┌─────────────────────────────────────────────────────────────────┐
│ STEP 1: BUAT REPOSITORY DI GITHUB                                │
└─────────────────────────────────────────────────────────────────┘

1. Login ke https://github.com
2. Klik "+" → "New repository"
3. Repository name: CO2
4. Pilih: Public
5. JANGAN centang "Initialize this repository"
6. Klik "Create repository"

GitHub akan kasih URL seperti:
https://github.com/USERNAME/CO2.git
(ganti USERNAME dengan username GitHub Anda)

┌─────────────────────────────────────────────────────────────────┐
│ STEP 2: BUAT PERSONAL ACCESS TOKEN (Untuk Password)             │
└─────────────────────────────────────────────────────────────────┘

1. Buka https://github.com/settings/tokens
2. Klik "Generate new token" → "Generate new token (classic)"
3. Token name: CO2-Upload
4. Pilih scope: ✓ repo
5. Generate token
6. COPY token (langsung simpan di notepad!)

Token hanya muncul 1x. Jangan lupa copy!

┌─────────────────────────────────────────────────────────────────┐
│ STEP 3: PUSH KE GITHUB (Terminal/PowerShell)                    │
└─────────────────────────────────────────────────────────────────┘

Buka PowerShell dan jalankan:

cd "d:\xampp8\htdocs\CO2"
git remote add origin https://github.com/USERNAME/CO2.git
git branch -M main
git push -u origin main

GANTI USERNAME DENGAN PUNYA ANDA!

┌─────────────────────────────────────────────────────────────────┐
│ STEP 4: SAAT DIMINTA PASSWORD                                    │
└─────────────────────────────────────────────────────────────────┘

Username: YOUR_GITHUB_USERNAME
Password: PASTE TOKEN YANG SUDAH DICOPY

(Bukan password GitHub biasa, tapi token!)

┌─────────────────────────────────────────────────────────────────┐
│ STEP 5: SELESAI! ✅                                               │
└─────────────────────────────────────────────────────────────────┘

Repository live di: https://github.com/USERNAME/CO2

Untuk buat live website:
1. GitHub repo → Settings → Pages
2. Branch: main
3. Save
4. Website live di: https://USERNAME.github.io/CO2/

═══════════════════════════════════════════════════════════════════

Contoh lengkap:

Misal USERNAME: ahmad-aziz

cd "d:\xampp8\htdocs\CO2"

Username: ahmad-aziz

BUTUH BANTUAN?

Error "fatal: could not resolve host"
→ Check internet connection

Error "403 Forbidden" 
→ Token salah atau expired, buat token baru

Error "repository not found"
→ URL GitHub salah

Beritahu error message jika masih ada masalah!
