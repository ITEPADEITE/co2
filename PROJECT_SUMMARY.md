# 📊 Project Summary - CO₂ Calculator Aplikasi

## 🎯 Deskripsi Project

**Atlas Karbon Kelas - CO₂ Calculator** adalah aplikasi web modern dan interaktif untuk menghitung emisi CO₂ yang diserap oleh pohon. Aplikasi ini terinspirasi dari program Atlas Karbon Kelas X1 di SMAN 4 Mataram dan dirancang dengan design yang menarik, responsif, dan user-friendly.

## 🎨 Fitur Utama

### 1. 🧮 Kalkulator CO₂ Interaktif
- Input lingkar pohon dalam cm
- Otomatis hitung diameter (Lingkar ÷ 3,14)
- Hitung serapan CO₂ (Diameter × 2,2)
- Support multiple pohon sekaligus
- Real-time calculation tanpa reload

### 2. 🌳 Database 8 Pohon Asli
Data lengkap dari SMAN 4 Mataram:
- 🥭 Manggga - 66,5 kg CO₂/tahun
- 🌳 Mahoni - 84,0 kg CO₂/tahun
- 🌲 Sengon - 105,1 kg CO₂/tahun ⭐ (Terbesar)
- 🌱 Pucuk Merah - 45,5 kg CO₂/tahun
- 🥝 Sawo - 59,5 kg CO₂/tahun
- 🌴 Palem - 49,1 kg CO₂/tahun
- 🍇 Manggis - 56,1 kg CO₂/tahun
- 🎄 Cemara - 77,0 kg CO₂/tahun
