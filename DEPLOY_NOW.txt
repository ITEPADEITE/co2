LANGKAH DEPLOY (Copy-Paste):
────────────────────────────────────────────────────────────────────

1. BUKA TERMINAL/POWERSHELL:
   - Windows: Tekan Win+R, ketik "powershell", Enter
   - Mac: Applications > Utilities > Terminal
   - Linux: Ctrl+Alt+T

2. MASUK KE FOLDER PROJECT:
   cd d:\xampp8\htdocs\CO2

3. INISIALISASI GIT LOKAL:
   git init
   git add .
   git commit -m "Initial commit: CO2 Calculator Aplikasi"

4. BUAT REPOSITORY BARU DI GITHUB:
   - Login ke https://github.com
   - Klik tombol + (kanan atas)
   - Pilih "New repository"
   - Nama: CO2
   - Pilih: Public
   - Jangan pilih "Initialize this repository"
   - Klik "Create repository"

5. COPY COMMANDS DARI GITHUB, ATAU JALANKAN INI:
   
   GANTI "YOUR_USERNAME" DENGAN USERNAME GITHUB ANDA:
   
   git remote add origin https://github.com/YOUR_USERNAME/CO2.git
   git branch -M main
   git push -u origin main

6. MASUKKAN PASSWORD/TOKEN:
   - GitHub akan minta authentication
   - Pakai GitHub password atau personal access token

7. TUNGGU PROSES UPLOAD:
   ⏳ Akan muncul "100% (XX/XX)" saat selesai

8. ENABLE GITHUB PAGES:
   - Di browser, buka GitHub repo Anda
   - Klik tab "Settings"
   - Scroll ke "Pages"
   - Branch: main
   - Folder: / (root)
   - Klik "Save"
   - Tunggu 1-2 menit...

9. AKSES LIVE LINK:
   https://YOUR_USERNAME.github.io/CO2/

SELESAI! 🎉
────────────────────────────────────────────────────────────────────

JIKA ERROR "fatal: not a valid remote repository url":
→ Cek USERNAME di URL, pastikan benar
→ Cek internet connection
→ Coba ulang dari step 5

JIKA ERROR "Permission denied (publickey)":
→ Setup SSH key atau pakai HTTPS dengan token
→ Cek https://docs.github.com/en/authentication

QUICK TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────

❌ Tidak bisa push?
   → git remote remove origin
   → git remote add origin https://github.com/USERNAME/CO2.git
   → git push -u origin main

❌ Pages tidak live?
   → Tunggu 2-3 menit
   → Refresh browser (Ctrl+F5)
   → Cek Settings > Pages
   → Cek branch = main

❌ Lupa password?
   → Buat Personal Access Token di GitHub Settings
   → Gunakan token sebagai password
